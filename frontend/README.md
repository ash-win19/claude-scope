# Claude Scope

> Inspect your UI. Prompt your AI.

Claude Scope is a developer tool that records a browser tab, detects UI state changes, inspects DOM components via accessibility snapshots, and generates structured system prompts for AI coding agents like Claude Code, Codex, and Cursor.

## Tech Stack

- React 18 + Vite + TypeScript
- React Router v6
- Zustand (global state)
- TanStack Query v5 (server state)
- Tailwind CSS v3 + CSS custom properties
- Radix UI (headless primitives)
- Lucide React (icons)
- MSW (mock API)

## Getting Started

```sh
npm install
npm run dev
```

The app runs at `http://localhost:8080`.
